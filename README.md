# Guess-Who-animal-version 🐾

Guess-Who-animal-version is a Python-based animal guessing game inspired by
the classic game Guess Who?.

The computer secretly chooses an animal, and the player tries to figure
out which animal it is by answering questions about its characteristics.
At the same time, the player gets assigned an animal that the computer asks questions to guess.
Whoever manages to guess first wins!

## How to Play

The computer will ask questions about your animal, such as:

- What class is it?
- What does it eat?
- Where does it live?
- Does it have fur?
- Can it fly?
- Does it have scales?
- How many legs does it have?

You can also make your own guesses about the computer's animal.

## Features

- 27 different animals
- Multiple categories of questions
- Animal habitats and geographical regions
- Physical characteristics
- Diet and animal classification
- Animal facts and conservation information
- The computer uses the answers it receives to narrow down the possible animals
- The computer can make its own guesses
